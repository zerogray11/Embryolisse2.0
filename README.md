**Spring Boot Backend** for Embryolisse 2.0 - Skincare Recommendation System
Project Overview
This backend handles the user questionnaire responses and provides personalized skincare product recommendations based on customer input.

✔ Built With: Spring Boot, PostgreSQL, JPA, Hibernate
✔ Key Features:

Save user responses from the skincare questionnaire
Recommend up to 5 personalized skincare products
Track most recommended products based on past responses
RESTful API endpoints for frontend integration

Tech Stack
Backend: Java 22, Spring Boot
Database: PostgreSQL
ORM: Hibernate, JPA
API Testing: Postman
